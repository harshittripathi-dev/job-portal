# UI/UX Design

Aim for a clean, professional job portal with restrained blue accents,
readable typography, generous whitespace, and responsive layouts.

-   Keep navigation and page spacing consistent.
-   Use clear form labels, inline validation messages, keyboard focus
    states, and accessible contrast.
-   Job cards should prioritize title, company, location/salary when
    available, description, and a clear action.
-   Keep a visible "Back to Website" link on internal pages where
    appropriate.
-   If recommendations are enabled, show the estimated match score,
    matched skills, missing skills, and a short explanation.
-   Do not label a feature as AI-powered unless it is actually connected
    and working.
-   Reuse existing CSS classes instead of duplicating large style
    blocks.
